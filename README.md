## ✨ Features
*   **Dynamic Content:** Utilizes AngularJS `ng-repeat` to dynamically render services and team data.
*   **Form Validation:** A fully functional contact form with client-side validation (disabled submit button until valid).
*   **Modern Layout:** Built entirely with custom CSS Grid and Flexbox (No Bootstrap or external UI libraries).
*   **Responsive Design:** Mobile-first approach ensuring the site looks great on all devices.
*   **Sticky Footer:** Implemented using modern CSS Flexbox for a polished user experience.

## 🛠️ Tech Stack
*   **HTML5:** Semantic structure.
*   **CSS3:** Custom styling, Grid, Flexbox, animations.
*   **AngularJS (1.8.x):** MVC architecture, data binding, form handling.
*   **Google Fonts:** Inter typeface for modern typography.
